# Check-back communication card

[Visual brief](brief.md) · [Full guide](index.html) · [Evidence](sources.md)

Use this paper exercise to practice one closed communication loop. Estimated time: 15 minutes.

## Write one concrete message

Choose an ordinary coordination task. Do not use passwords, financial account details, medical information, or another person's private data.

- Person: `________________________`
- Action: `________________________`
- Time or sequence: `________________________`
- Place or destination: `________________________`
- Other outcome-changing detail: `________________________`

Now write the shortest complete message:

`__________________________________________________________________`

## Close the loop

1. The sender says or sends the message once.
2. The receiver repeats the outcome-changing details in their own words.
3. Without showing their notes, the sender marks each detail:

| Detail | Match | Correct and repeat |
| --- | --- | --- |
| Person | [ ] | [ ] |
| Action | [ ] | [ ] |
| Time or sequence | [ ] | [ ] |
| Place or destination | [ ] | [ ] |
| Other | [ ] | [ ] |

4. If one item differs, the sender corrects only that item and asks for it again.
5. Stop when the actionable versions match.

## Reflect

- Which detail was easiest to distort or omit? `________________________`
- Would a safer channel be needed for any real detail? `yes / no`
- What has **not** been verified: memory, consent, completion, or something else? `________________________`

## Answer guidance

A useful check-back repeats the details that can change the outcome. “Okay” is an acknowledgment, but it gives the sender nothing specific to compare. A matching repeat verifies the message at that moment; follow-up may still be needed for understanding, consent, memory, or completion.

**Observable success:** Both people state the same person, action, time or sequence, and place without looking at each other's notes, while identifying at least one thing the check-back does not prove.
