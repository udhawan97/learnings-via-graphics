### A hill, a heat pump and a book fair

![Two paths climb from 100 to 140 metres. Path A crosses closely spaced contour lines over 100 horizontal metres. Path B spreads the same climb over 400 metres.](editions/2026-11-15-reading-contours/assets/contours.svg)

**Both paths reach the same height. Which would you expect to climb more gently?**

<details>
<summary>Check your map reading</summary>

Path B spreads the same 40-metre rise over four times the horizontal distance. Its average grade is 10%. Path A’s is 40%. The drawing tells you the slope, while the footing needs a separate check.

</details>
