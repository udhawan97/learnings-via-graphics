# Contributing to Learnings via Graphics

For each editorial commit, apply the [newsletter story selection rule](docs/editorial-standards.md#choose-the-next-newsletter-story). Check the staged change with `python3 scripts/check_coverage.py --base origin/main`, or use the handbook’s GitHub-only comparison. Record the reader outcome and coverage result in the PR.

Use the [contribution checklist](CONTRIBUTING.md) for the brief, accessible diagram, activity, sources and review. Follow the [delivery guide](docs/default-branch-delivery.md) for this source-only publication.
